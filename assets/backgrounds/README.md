# Portal background assets

Upload the two portal background images into this folder using these exact filenames:

- `canela-light-background.jpg`
- `canela-dark-background.jpg`

The portal theme system references these exact paths:

- `./assets/backgrounds/canela-light-background.jpg`
- `./assets/backgrounds/canela-dark-background.jpg`

Keep the filenames lowercase and preserve the `.jpg` extension so the theme switcher works without further code changes.
